# Ellen Lyon Website

Complete static website with three pages, images, review carousels, and the original Word review download. No build step is needed.

## Upload to GitHub

1. Extract this ZIP.
2. Open your GitHub repository and select **Add file → Upload files**.
3. Upload the contents of this folder, preserving the assets, about-us, and contact-us folders. Put index.html at the repository root.
4. Commit the files.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**, select your main branch and **/ (root)**, then Save.

Links are relative so the site supports a GitHub Pages project subfolder or a custom domain. Fonts load from Google Fonts; Amazon and social links require an internet connection. Email buttons open the visitor's email application. Newsletter signup is not included.

The export retains the Still Waters hero, all 23 reader photos and 19 review entries. Home address, phone numbers, X, LinkedIn, ministry program section, reviewer resources, and original ellenlyon.com links have been removed.

## Local preview

Run `python -m http.server 8000` from this folder, then open http://localhost:8000 in your browser.
